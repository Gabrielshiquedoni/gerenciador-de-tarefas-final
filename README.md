📝 Gerenciador de Tarefas (Task Manager)
Este é um projeto desenvolvido para a disciplina de Programação de Soluções Computacionais no Centro Universitário Senac. O objetivo é oferecer uma ferramenta de produtividade que permite ao usuário organizar suas atividades diárias de forma eficiente.

🚀 Tecnologias e Conceitos Aplicados
Linguagem: Java.

Framework: Spring Boot (Criação de APIs REST).

Persistência de Dados: MongoDB (NoSQL) para armazenamento flexível de tarefas.

Arquitetura: Divisão em camadas (Controller, Service, Repository) para facilitar a manutenção.

Metodologia: Implementação completa de operações CRUD.

⚙️ Funcionalidades
Cadastro de novas tarefas com título, descrição e prioridade.

Listagem dinâmica de atividades pendentes.

Atualização de status (ex: de "Pendente" para "Concluído").

Exclusão de registros do banco de dados.
